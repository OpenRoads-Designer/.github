## What OpenRoads Designer Is

OpenRoads Designer is a civil roadway workspace where the corridor model follows alignment, profile, and terrain. OpenRoads Designer alignment and profile set the horizontal path and the vertical grade. OpenRoads Designer corridor model builds lanes, shoulders, and slopes along that path. OpenRoads Designer terrain surface holds existing ground under the civil roadway layout so cuts and fills stay tied to the same model.

Road teams open OpenRoads Designer when a roadway must be shaped from one alignment rather than from disconnected drawings. Stationing, profile grades, and terrain triangles stay visible while the corridor updates. OpenRoads Designer keeps the civil roadway layout on the alignment, profile, and terrain you will review.
